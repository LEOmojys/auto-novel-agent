# 回滚流程

用户要**删除已写内容**（"把刚写的东西删掉 / 回退到第 N 章之前 / 不要了"）时走此流程。

## ⚠️ 硬删除警告

回滚 = **物理删除文件**，不可恢复。**执行前必须向用户明确确认**，列出将要删除的文件。

## 步骤

1. **确认意图**：明确"删到哪"——
   - "删掉刚写的" → 删除最新一章
   - "回退到第 N 章之前" → 删除 `chapters/N.json` 及之后所有章节
2. **列出影响**：向用户展示将删除的 `chapters/*.json`（文件名 + 标题），请求确认。
3. **删除**：
   - 删除对应章节文件
   - 回退 `memory.json`（移除被删章节新增的角色状态/伏笔、恢复"已写章节号"）
   - 回退 `project.json` 的 progress
   - 可选：在 `quality_log.json` 记录一次"rollback"操作（保留痕迹）
4. **汇报**：当前剩余章节、回滚后进度。

## 注意

- 只删章节文件；**不删** `world.json` / `characters/` / `outline.json`（除非用户明确要求"整个重来"）。
- 若用户要"整个项目删掉"→ 提示确认后删除整个 `novels/<名字>/` 目录。
- 回滚后继续创作走 `continue.md`（从剩余最大章号 + 1 开始）。
