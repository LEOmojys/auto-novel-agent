# 查询进度流程

用户问"写到哪了 / 有哪些角色 / 现在什么状态"时走此流程，**只读不改**。

## 步骤

1. **定位项目**：`novels/<名字>/`。用户没给名字时列出所有 `novels/` 下的项目。
2. **汇总**：
   - `project.json`：标题、简介、类型、目标章数、progress（已写章节）
   - `outline.json`：总章数、当前到第几章
   - `memory.json`：当前状态、未回收伏笔数、角色数
   - `chapters/`：实际文件数（与 progress 核对，发现不一致要指出）
3. **汇报**：给用户清晰摘要（不贴全文）。

## 注意
- 只读命令，禁止改动任何文件。
- 若发现"progress 与实际文件不一致"（异常），如实汇报并建议修复。
