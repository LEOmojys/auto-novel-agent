# PlanAct 工作范式

PlanAct = **Plan → Act → Observe → Adjust**。这是本 skill 的核心工作方式。

## 流程

```
用户需求
  → 意图分析（新建 / 续写 / 修订 / 回滚 / 查询）
  → 规划（Plan）：列出步骤，按依赖排序
  → 执行（Act）：逐项执行（调 LLM → 写 JSON）
  → 观察（Observe）：看每步结果
  → 调整（Adjust）：发现问题改计划 / 改内容
```

## 依赖顺序（小说领域）

```
世界观 world.json → 角色 characters/*.json → 大纲 outline.json → 章节 chapters/N.json
```

- 写角色前必须有世界观（人物行为要符合世界规则）
- 写大纲前必须有角色（剧情围绕人物）
- 写章节前必须有该章大纲（goal/beats）

## 规划示例（新建一部小说）

```
计划：
1. 建目录 + project.json
2. 生成世界.json（前提/规则/地点）
3. 生成主要角色（主角 + 2-3 重要配角）
4. 生成大纲（目标 10 章）
5. 写第 1 章 → 审查 → 更新记忆
6. 写第 2 章 → 审查 → 更新记忆
...
```

## 关键原则

- **先规划后执行**：不要拿到需求就直接写正文
- **按依赖推进**：不跳步（没有世界观就写角色是错的）
- **执行中可调整**：写了 3 章发现角色设定有问题 → 停下来修设定 + 受影响章节，不硬写
- **每步落盘**：每生成一个产物立刻写文件（不要攒到最后一起写）
